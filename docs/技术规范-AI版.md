# 不规则动词 · 技术规范

更新：2026-11-10 21:48 PST

## 入口和存放

GitHub 仓库：`Baiiugun/irregular-verbs-study-and-practice`。本目录是部署工作副本。源学习页仍在用户指定的语法作业文件夹。新增任务文件只存本项目目录。

学生页 `index.html`；老师页 `不规则动词学习记录-老师登录版本.html`；发布方式 GitHub Pages，`main` 根目录，`.nojekyll`。不要更改仓库可见性，除非用户另行同意。

## 数据

词表沿用教材版初中 001—098、高中 001—128 原编号。原形/过去式/过去分词的提示列排第一，中文永远保留。合法变体可填写一种或用斜线列出多种。302 段发音内置；read 的原形和变形分开。练习本地状态按学生 UUID 存储；不把练习答案上传。

`iv_students(id,name,created_at)` 缩写归一为大写、唯一。`iv_assignments` 按学生+日期+版本唯一，重复保存更新范围。`iv_visits` 每次页面进入一行，随机 UUID 访问 id 与随机写令牌；只记录时间、前台累计毫秒和心跳序号。

## 权限

沿用现有 Supabase URL、anon 公开 key、Auth 邮箱密码登录和 `public.is_teacher()`。不得写入老师密码、service_role、真实学生数据或真实访问令牌。

三表开启 RLS；anon 无直接读写；authenticated 只有老师可读。所有写操作经限定 RPC。老师 RPC 还调用 `iv_require_teacher()`，非老师拒绝。学生只能用访问 id+随机令牌写自己的时长，不能查学生列表和历史。

名字缩写是老师给的识别标签，不是身份认证；知道同一缩写的人可以登记到这个标签下，但不能用自己的新访问令牌修改已有访问。老师只用时段做大致观察，不把它作为严格身份认证或学习成果证明。

## 计时

`PresenceClock` 用单调时钟，仅在页面可见且窗口有焦点时累计。约 20 秒一次心跳，后台暂停，退出用 keepalive 尽力补发。累计值+递增序号让重复/乱序请求不重复计时；服务器按实际经过时间限制一次增加的上限。老师按设备时区筛选日期，约 15 秒刷新。

## 删除

本次用户明确要求允许删除本练习里有记录的学生，优先于旧 Anki 系统只能停用的规则。老师输入完整缩写后 RPC 删除 iv_students 并级联删除 iv_assignments/iv_visits。绝不触碰 anki_test_*、其他学生或文件词库。新登记同名缩写得到新 UUID，原访问令牌失效。

## PDF

junior-study.pdf = 初中“看变形答原形加中文-编号版”；junior-spelling.pdf = 初中拼写版；senior-study.pdf = 高中“看变形-答原形加中文”；senior-spelling.pdf = 高中拼写版。两按钮随顶部版本切换。测试核对 SHA-256 与用户指定原件相同。

## 发布和数据库

用户本次已明确授权推到上述 GitHub 和 Supabase。可以推送指定仓库，不能私自改私有为公开。Supabase Studio 运行 SQL、老师密码由用户本人处理：见项目根入口以及原系统技术规范 §14。SQL 文件已在内存 PostgreSQL 跑过两次验证幂等，线上需用户完整运行 11 号文件；之后用 anon 只读核对接口开放情况，不创建真实测试学生。
