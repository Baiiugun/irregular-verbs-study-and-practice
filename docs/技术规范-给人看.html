老师：缩写 + 日期
初中/高中 + 起止编号
→
学生：打开链接
填写缩写开始学习
→
Supabase
保存布置和访问时段
→
老师：查看
进入时间与前台停留

你会用到两个页面

学生页：初中 98 词、高中 128 词，自由切换。选范围、学习、回忆、批改、手写自评、乱序、Reset 都保留。每个版本都有两个 PDF 下载按钮。

老师登录版本：用现有老师账号登录，添加学生、布置词汇、复制学生链接，并按日期查看访问明细。

记录的时长是什么意思？

学生不需要打字或交卷。页面在前台时累计，切到后台暂停。大约每 20 秒更新一次，老师页面约 15 秒刷新。它只能说明网页大致停留了多久，不能证明孩子是否专心或已经背会。

云端只保存缩写、布置和时间，不保存答案或按键。页面显示的时刻跟随当前设备时区。

名字与删除

学生用 LXM 这样的缩写即可。老师也可以先添加缩写、布置任务，再复制预填名字的链接给学生。

删除前需要输入完整缩写。删除本练习中的学生、布置和访问记录后，缩写可以重新登记；初高中词表与 PDF 保留。

启用云端还差什么？

老师本人在 Supabase 的 SQL Editor 新开查询，完整运行 sql/11-不规则动词-学生布置与停留记录.sql。不需要把老师密码给 AI，也不用把密码写进网页。

GitHub Pages 启用后才有可发给学生的网址。仓库当前是私有，发布状态以操作记录为准。
